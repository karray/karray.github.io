{%- comment -%} Reusable heatmap grid: a fixed set of images, each shown with exactly one heatmap overlay, laid out as a plain grid - no dock, no row/column axes. For a gallery where the reader switches between many variations of a single photo, use figure-gallery.html instead. {% include heatmap-grid.html id="lrp-samples" data=site.data.galleries.lrp_samples %} The `data` object (usually a file under _data/galleries/) accepts: items required. [{label, src, overlay, alt?, tiles?, rendering?}] - one card each. `overlay` is that card's heatmap image; `tiles` fixes the reveal grid instead of taking it from the map's own resolution, `rendering: auto` scales it smoothly instead of nearest-neighbour. columns fixed number of grid columns, held at every width down to the narrow-screen breakpoint, where the cards wrap instead. Omitted, they always wrap to fit (--hg-card-min). kicker, caption, help text, all optional. opacity initial overlay opacity in percent (default 100). reveal `false` drops the reveal gesture and its control. The gesture cuts each heatmap into tiles that fall away around the pointer; tune it per instance with --hg-reach and --hg-depth. style extra CSS custom properties for this instance. Anything not supplied is skipped, so a minimal grid needs only `items`. {%- endcomment -%} {%- assign g = include.data -%} {%- assign uid = include.id | default: g.id | default: 'heatmap-grid' | slugify -%} {%- assign items = g.items -%} {%- assign kicker = include.kicker | default: g.kicker -%} {%- assign caption = include.caption | default: g.caption -%} {%- assign help = include.help | default: g.help -%} {%- assign opacity = g.opacity | default: 100 -%} {%- assign reveal = true -%}{%- if g.reveal == false -%}{%- assign reveal = false -%}{%- endif -%} {%- assign style = include.style | default: g.style -%} {%- unless heatmap_grid_assets -%} {%- assign heatmap_grid_assets = true -%} {%- endunless -%}
