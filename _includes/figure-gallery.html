{%- comment -%} Reusable figure gallery: a dock-style image picker over a grid of panels, where every panel shows one image plus an optional overlay (heatmap, mask, segmentation, ...). {% include figure-gallery.html id="lafam-encoders" data=site.data.galleries.lafam_encoders %} The `data` object (usually a file under _data/galleries/) accepts: items required. [{id, label, src, thumb?, overlay?}] - the dock. columns required. [{label, layer?, alt?, rendering?, tiles?}] - one panel column each; a column without `layer` shows the bare image, `rendering: auto` scales its map smoothly instead of nearest-neighbour, and `tiles` fixes the reveal grid instead of taking it from the map's own resolution. rows required. [{id, label}] - one panel row each. Use a single row with an empty label for a gallery with no row axis. overlay overlay path template; `{item}`, `{row}` and `{layer}` are substituted. Per-item `overlay` overrides it. kicker, caption, help, row_header text, all optional. opacity initial overlay opacity in percent (default 100). reveal `false` drops the reveal gesture and its control. The gesture cuts the map into tiles that fall away around the pointer; tune it per instance with --fg-reach and --fg-depth. style extra CSS custom properties for this instance. Anything not supplied is skipped, so a minimal gallery needs only `items`, `columns` and `rows`. {%- endcomment -%} {%- assign g = include.data -%} {%- assign uid = include.id | default: g.id | default: 'figure-gallery' | slugify -%} {%- assign items = g.items -%} {%- assign columns = g.columns -%} {%- assign rows = g.rows -%} {%- assign first = items[0] -%} {%- assign kicker = include.kicker | default: g.kicker -%} {%- assign caption = include.caption | default: g.caption -%} {%- assign help = include.help | default: g.help -%} {%- assign opacity = g.opacity | default: 100 -%} {%- assign reveal = true -%}{%- if g.reveal == false -%}{%- assign reveal = false -%}{%- endif -%} {%- assign style = include.style | default: g.style -%} {%- assign row_labels = rows | map: 'label' | join: '' | strip -%} {%- comment -%}Liquid ends a variable at the first `}`, so the placeholders are captured as literal text.
