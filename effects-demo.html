Tile effect sandbox

Three effects, one engine. Hover applies the effect locally around the pointer; press and hold sends the same effect across the whole map as a wave from the point you pressed, and releasing plays that wave backwards — the tiles that left last return first.

Sections R and S run identical code and identical numbers over a 12×12 and a 7×7 grid. Every distance is a percentage of a tile, a unitless scale, or a depth in px, and the wave delay is normalised, so nothing is tuned per resolution. Add ?pin to freeze the hover state or ?pin=hold to freeze the pressed state.
